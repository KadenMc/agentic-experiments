## Statement

_The forward-looking concern, question, or research direction this
thread captures. Broader than a single hypothesis — a thread is the
*aggregate* exploration that may spawn 2–5 hypotheses over its
lifetime. Don't confuse a thread with a hypothesis: hypotheses are
falsifiable claims with a test plan; threads are the surrounding
context that motivates choosing which hypotheses to write._

## Promotion criteria

_When does this thread spawn its first hypothesis? Be specific about
the prerequisites — empirical baselines, design decisions, external
dependencies (collaborator input, dataset availability, etc.). The
purpose is to keep the thread from drifting into a permanent
"exploring" state with no exit condition._

## Open links

_External references that bear on this thread: papers, code paths,
prior threads, sessions where the thread surfaced, outreach in
flight. Distinct from ``## Links`` (which validates wikilinks within
the kb graph) — Open links can be free-form Markdown links or notes._

## Notes

_Running journal of thinking on this thread. Date-stamped entries
recommended. Lives WITH the thread, not in session notes — session
notes rot; this section is the durable record of how the thread
evolved._

## Conclusion

_Filled when the thread closes. For ``status: CLOSED`` (decided not
to pursue / out of scope / superseded), state why. For ``status:
PROMOTED`` (one or more hypotheses spawned and the thread is now
parent-context), the conclusion can be a brief pointer to the H###
artifacts that carry the actionable claims._
